# IMONSOFT Files 0.2 — рабочие процессы и 33 инструмента

## Новые операции

Визуальная организация страниц PDF; обрезка видимых полей; текстовый экспорт PDF в DOCX и Markdown; извлечение встроенных растровых изображений; растрирование страниц; диагностический JSON-отчёт; поворот, отражение и оттенки серого для изображений. Каталог вырос с 23 до 33 операций без добавления неработающих плиток.

## Работа с файлами

Редактор страниц поддерживает миниатюры, drag-and-drop, кнопки для клавиатуры и телефона, поворот, удаление, обратный порядок, восстановление, отмену и повтор. Группы по 24 миниатюры ограничивают число одновременно отрисованных страниц. Смена файла сбрасывает старый план.

Пакетная обработка даёт отдельные результаты в ZIP с JSON- и текстовым отчётами. Частичный успех отображается отдельным предупреждением, счётчиком и состоянием истории, а не безусловным «всё готово». Новая задача может использовать готовый результат на сервере. Office и изображения при конвертации в PDF могут сразу применить водяной знак, нумерацию или оптимизацию.

Добавлены группы страниц при разделении, выбор страниц в PPTX/OCR, параметры водяного знака, пароль для локального предпросмотра, прямой переход к странице и увеличенный просмотр. История получила поиск, фильтры и подтверждаемую очистку завершённых результатов; активные задачи не удаляются этой командой.

## Инженерные изменения

- Проверяемые лимиты multipart до записи всех частей на диск; ограничение одновременных приёмов и частоты запусков.
- Логические бюджеты хранения с резервом будущего результата, проверка свободного диска, конфигурируемые размеры результата и числа файлов.
- Необязательный общий пароль пространства, scrypt, ограничение попыток входа, защита OpenAPI и job endpoints. Пароль по умолчанию не установлен.
- Миграция SQLite для структурированного batch-результата; очистка job scratch; восстановление прерванных задач после перезапуска.
- Корректные водяные знаки на повёрнутых страницах с нестандартными координатами CropBox; разыменование косвенных ссылок при диагностике PDF.
- Python lockfiles с проверяемыми хешами; Node lockfile; тесты реальных выходных байтов и пиксельного соответствия; браузерные и автоматические accessibility-проверки.

## Границы выпуска

PDF → PPTX остаётся изображением страницы на слайде. DOCX/Markdown — экспорт текста, не восстановление дизайна. CropBox не удаляет скрытые данные и не заменяет redaction. Растрирование не сохраняет текст, векторы, формы или подписи. Шрифты и сложные эффекты Office требуют отдельной проверки на реальных исходниках.

Общий пароль не является SSO или многопользовательской моделью. Процессы конвертации имеют общий контейнер/UID: публичный анонимный SaaS требует более строгой изоляции. Ветка выпуска — `feat/platform-foundation`, PR #1; слияние в `main` выполняется только отдельным решением.
