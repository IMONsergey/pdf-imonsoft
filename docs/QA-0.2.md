| Автоматическая доступность | axe: выбранные экраны, миниатюры и увеличенный просмотр, светлая/тёмная темы; нарушений проверенных WCAG A/AA-правил не обнаружено |

В браузере проверены: поиск/темы/навигация, реальные PDF ↔ PPTX, обработка и скачивание, история, недопустимые/пустые файлы, порядок файлов, редактор с undo/redo, смена исходника, частично успешная пачка, передача результата без повторной загрузки, очистка завершённых задач, пароль PDF/перелистывание/modal, Office с водяным знаком, текстовый DOCX и группы миниатюр.

Матрица API (`scripts/check-api-matrix.py`) последовательно создаёт задачи всех 33 инструментов, проверяет PDF/PPTX/DOCX/изображения/JSON/ZIP и удаляет созданные задачи. OCR и Office выполняются установленными Docker-движками. Отчёт по запуску сохраняется локально в `.data/qa/v02-api-matrix.json`, не в Git.

Вход по паролю: реальный scrypt и ограничения доступа проверены серверными тестами; отдельный UI-сценарий использует перехват API и не является end-to-end тестом реальной авторизации. Пароль рабочего пространства владельцу не устанавливался.

GitHub Actions запускает тот же backend с установленными LibreOffice/Tesseract на Linux и браузерные проверки. Актуальный статус последнего коммита проверяется в PR #1; локальные результаты не подменяют его.

Ограничения: это не нагрузочный тест, не аудит нативных бинарных движков, не полная проверка доступности и не доказательство точной конвертации сложных клиентских презентаций. PDF → PPTX — изображения; DOCX/Markdown — текст без восстановления вёрстки. Для публичного запуска остаются требования SECURITY.md.
