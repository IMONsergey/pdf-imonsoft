# План развития после 0.2

## Реализовано

33 операции; общий каталог форматов; русский адаптивный интерфейс и темы; защищённый локальный предпросмотр PDF; визуальный редактор порядка страниц; пакетная обработка с отчётом; следующий шаг без повторной загрузки; дополнительные операции после Office/Image → PDF; поиск и фильтры истории; подтверждаемая очистка завершённых задач.

FastAPI, SQLite-очередь, subprocess timeout/cancel, сессионная принадлежность, TTL, ограничение приёма multipart и частоты запусков, логические бюджеты хранения, необязательный общий пароль пространства, миграции и очистка временных файлов. Зависимости зафиксированы, добавлены серверные, браузерные, пиксельные и автоматические проверки доступности.

## Ближайшие приоритеты

1. Матрица качества на реальных презентациях: легально установленные шрифты, SVG, таблицы, прозрачность, диаграммы, master layouts. Не коммитить документы клиента и шрифтовые бинарные файлы. Не объявлять совместимость с PowerPoint по одним синтетическим файлам.
2. Улучшение работы с большими документами: серверный предпросмотр по запросу, единый PDF cache в пределах экрана, drag между группами миниатюр, отдельные лимиты/таймауты batch и непрерывная доступная индикация долгих операций.
3. Надёжность задач: идемпотентный запуск, возобновление загрузок, автоматический retry только безопасных операций, диагностика диска/памяти/очереди без содержимого документов.
4. Публичная модель: SSO/учётные записи, межустройственная история, tenant ownership, пользовательские квоты, API-ключи, отзыв сессий, изолированные disposable worker-контейнеры и внешний брокер.
5. Общая экосистема: конфигурация white-label сборок, локализация, интеграции API/n8n. Не добавлять новые категории ради количества.

## Отдельное исследование, не обещание готового результата

Редактируемая реконструкция PDF → PPTX/DOCX с точной вёрсткой; полноценный PDF text editor; цифровые подписи и формы; медиа/архивы/3D; универсальные цепочки из произвольного числа преобразований. Для каждого направления нужны тестовый корпус, ограничения качества, проверка лицензий и изоляции.

Версия остаётся личной/командной утилитой в доверенной инфраструктуре. Общий пароль не превращает её в готовый анонимный публичный SaaS.
