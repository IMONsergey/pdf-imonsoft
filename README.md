# IMONSOFT Files

Собственная self-hosted платформа для работы с PDF, презентациями, документами и изображениями. Русский интерфейс, светлая и тёмная темы, 23 реализованных операции. Без платного API и чужого интерфейса внутри приложения.

**Важно:** PDF → PPTX сохраняет внешний вид страниц как изображения на слайдах. Это не восстановление редактируемых текстовых блоков, графиков или фигур. Никаких обещаний «идеальной обратной конвертации».

## Запуск

Нужны Docker и Docker Compose. Рекомендуется выделить Docker не менее 5 ГБ памяти. Первый запуск собирает образы; последующие используют кэш.

```bash
cp .env.example .env
docker compose up --build -d
```

Откройте **http://127.0.0.1:8080**. По умолчанию приложение доступно только на локальном компьютере. API и Gotenberg не публикуют порты. Состояние движков отображается в интерфейсе; недоступный движок не изображает успешную обработку.

```bash
docker compose ps
docker compose logs --tail=80 api gotenberg
docker compose down                 # остановка, данные сохраняются
```

Не используйте `down -v` без необходимости: этот флаг удаляет том с результатами и ключом сессий.

## Что работает

| Раздел | Операции |
|---|---|
| Презентации | PPT/PPTX/ODP → PDF; PDF → PPTX (изображения слайдов) |
| PDF | Объединение; разделение; выбор, удаление и перестановка страниц через диапазоны; поворот; оптимизация; защита паролем; снятие защиты с известным паролем; водяной знак; нумерация; удаление стандартных метаданных |
| Из PDF | JPG/PNG; извлечение текстового слоя; OCR сканов на русском и английском |
| Документы | DOC/DOCX/ODT/RTF → PDF; XLS/XLSX/ODS → PDF |
| Изображения | Изображения → PDF; PNG/JPEG/WebP; пропорциональное изменение размера; оптимизация |

Полный реестр форматов, параметров и предупреждений: `shared/tools.json`. Браузер и API используют **один реестр**, без двух расходящихся списков функций.

В интерфейсе доступны локальный предпросмотр PDF, выбор и порядок файлов, реальные статусы загрузки и очереди, отмена, скачивание, история текущей браузерной сессии и удаление результата. Процент отображается только когда движок умеет сообщить измеримый прогресс.

## Архитектура

```text
Browser → Nginx → FastAPI + SQLite job queue → dedicated worker process
                                               ├─ pypdf / PDFium / python-pptx
                                               ├─ Pillow / Tesseract / ReportLab
                                               └─ internal Gotenberg → LibreOffice
```

Frontend: React + TypeScript + Vite. Backend: Python + FastAPI. Office: Gotenberg 8.37.0. Установка не зависит от Transmute, ConvertX, BentoPDF или их AGPL-кода.

**Это первая рабочая версия для собственной инфраструктуры, не публичный анонимный SaaS.** До открытия доступа в интернет нужны учётные записи/SSO, ограничения по пользователю/IP, мониторинг, проверка изоляции и отдельная политика хранения. Сессионная изоляция задач не заменяет аутентификацию.

## Брендинг

- `apps/web/src/lib/brand.ts` — название и подписи.
- `apps/web/src/styles.css` — токены цветов, типографика, размеры, темы.
- `apps/web/public/favicon.svg` и компонент `Brand` — собственный знак.
- `apps/web/index.html` — title/description.
- Никаких удалённых шрифтов, аналитики или рекламных запросов в интерфейсе.

## Ограничения обработки

По умолчанию: 50 МБ на суммарную загрузку, 20 файлов, 200 страниц PDF, 3 активные задачи на сессию и 24 на сервер. Время одной задачи — 180 секунд, хранение — 1 час **от загрузки**. Исходники и временный файл с паролями удаляются после завершения/ошибки/отмены; результат удаляется при истечении срока (фоновый сборщик до 30 секунд задержки). После истечения скачать его уже нельзя.

Лимиты меняются в `.env`. При увеличении размера загрузки согласуйте `MAX_UPLOAD_MB`, `MAX_REQUEST_MB` и `--api-body-limit` Gotenberg. Не запускайте API с несколькими Uvicorn workers и не масштабируйте API на общий SQLite: этот этап использует один диспетчер очереди. Для горизонтального масштабирования нужен отдельный брокер и воркеры.

Экспорт Office зависит от шрифтов LibreOffice и поддерживаемых эффектов. PDF-OCR создаёт растровый PDF с текстовым слоем. Оптимизация PDF не всегда уменьшает размер. Удаление метаданных не является полной анонимизацией. Изменение подписанного PDF нарушает его цифровую подпись. Сохраняйте оригиналы.

## Разработка без Docker

Python 3.13+, Node 24. Office/OCR требуют установленных LibreOffice и Tesseract. Для доверенных локальных тестовых файлов:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r services/api/requirements-dev.txt
cd services/api
OFFICE_ENGINE=local uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
# В другом терминале:
cd apps/web
npm ci
npm run dev
```

Vite открывается на http://127.0.0.1:4173 и проксирует `/api` на порт 8000. В PowerShell задавайте переменные окружения синтаксисом `$env:...`. В macOS для LibreOffice задайте `LIBREOFFICE_BIN=/Applications/LibreOffice.app/Contents/MacOS/soffice`.

## Проверки

```bash
cd services/api && python -m pytest tests -q
cd ../../apps/web && npm ci && npm run build
# Для E2E запустите API, затем из корня:
python scripts/make-fixtures.py
cd apps/web && npx playwright install chromium && npm run test:e2e
```

Фикстуры синтетические. Документы пользователя, пароли и ключи не включаются в Git. CI запускает серверные и браузерные тесты, включая реальный локальный экспорт презентации в PDF.
